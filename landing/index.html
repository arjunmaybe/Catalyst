01 — Entry

Floating file converter for Windows

A file converter that lives on your desktop, not in a browser tab.

Catalyst sits on your screen as a small disc. Drag a file onto it, release over a format in the ring, and the converted copy lands next to the original. Conversion runs on your own machine, so nothing uploads anywhere.

02 — Recording

Recorded on Windows, not drawn for this page.

A file dragged onto the disc, a format picked from the ring, the converted copy saved beside the original.

What to watch for

  1. Drop. A file lands on the disc and the ring opens with valid targets only.
  2. Pick. The cursor moves to a format node and the choice highlights.
  3. Done. The converted copy appears beside the original. Nothing uploads.

03 — Formats

Twelve targets across three kinds of files.

JPEG files save as JPG. Converted copies are named <name>_catalyst.<ext> and land next to the original.

Supported formats: what Catalyst reads, what it writes, and which engine converts it
Kind Reads Writes Engine
Images JPG, JPEG, PNG, BMP, GIF, TIFF JPG, PNG, BMP, GIF Rust image crate
Video MP4, MKV, MOV, AVI, WEBM MP4, MKV, MOV, WEBM Bundled ffmpeg binary
Audio MP3, WAV, M4A, FLAC, OGG MP3, WAV, M4A, FLAC Bundled ffmpeg binary
  • Format conversion only. No compress, crop, trim, metadata, or PDF tools.
  • A few unusual JPEG encodings cannot be decoded by the image library in use. The widget says so plainly (“unsupported JPEG variant”) instead of failing silently.
